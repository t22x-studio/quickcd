# Quick Chinese & Jyutping Dictionary
A lightweight, high-performance web-based Chinese dictionary focused on Cantonese (Jyutping), Mandarin (Pinyin/Zhuyin), radicals, English definitions, and Cangjie input codes.

Designed to run instantly in any browser with zero complex backend setup.
- - -
**Key Features**
1. Multi-Modal Search: Instantly search by Chinese characters, English keywords, Jyutping, Pinyin, or Radicals.
2. Cangjie Integration: Automatically maps Cangjie codes (ddd) to visual component breakdowns (木木木) with quick-search tags.
3. Result Filters: Instantly toggle between All, 1 Character, and 2 Characters right below the search bar.
4. Instant Detail View: Click any character or search results card to see a comprehensive breakdown of pronunciations, radicals, and stroke counts.
5. Mobile Friendly: Fully responsive layout optimized for seamless use on phones, tablets, and desktops.
